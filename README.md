# 🛒 price-bot — бот знижок для Вінниці та Іллінців

Личный Telegram-бот, который показывает акции **именно твоих магазинов**:

| Магазин | Точка | Как получаем данные |
|---|---|---|
| 🟢 Сільпо | Вінниця, вул. Зодчих, 2 | внутренний REST API магазина |
| 🔵 АТБ | Вінниця, вул. Київська, 27 | страница «Економія» + привязка к магазину |
| 🟠 Фора | Вінниця, вул. Чорновола, 29Б | JSON API группы Fozzy |
| 🟣 Грош | Вінниця й область | JSON API платформы Salesbox |

Есть и магазин в Іллінцях (вул. Європейська, 22) — переключается в `region.py`.

## Как это работает

Бот раз в 3 часа скачивает **каталог акций** твоих магазинов и держит его
локально. Поэтому:

- ⚡ **поиск мгновенный** — 50 мс вместо 30 секунд;
- 🎯 **ищет простыми словами** — «макарони» находит «Макаронні вироби»
  и «Спагеті», «чіпси» находит «Чипси», «кола» находит «Coca-Cola»;
- 🤝 **сайты почти не нагружаются** — один обход вместо десятков поисков.

## Что умеет

| Команда | Что делает |
|---|---|
| просто написать товар | 🔍 поиск акций (можно несколько через запятую) |
| `/deals` | 🔥 **всі акції** — витрина с фото, листается по страницам |
| `/top` | 🏆 **топ найбільших знижок** прямо сейчас |
| `/compare молоко` | ⚖️ **сравнить цены** на товар между всеми магазинами |
| `/list` | 🧾 **список покупок** — проверить все позиции разом |
| `/watch кава` | 👀 **следить за товаром** — уведомление при появлении скидки |
| `/stores` | 🏪 выбрать магазины для поиска |
| `/refresh` | 🔄 обновить каталог акций принудительно |

Под каждым результатом — кнопки «Порівняти ціни», «Стежити», «У список покупок».

### Красивый вывод

Используются **Rich Messages** (Telegram Bot API 10.2, июль 2026):
у каждого товара своё фото, рядом — магазин, название-ссылка,
старая → новая цена и процент скидки. Плюс заголовки, таблицы и футер.
Если твой Telegram старый — бот автоматически пришлёт аккуратный текст.

# Установка на macOS

## Шаг 1. Проверь Python

```bash
python3 --version
```
Нужен 3.11+. Если нет — https://www.python.org/downloads/

## Шаг 2. Получи проект

```bash
git clone https://github.com/xxxquide/Discount-Find.git price-bot
cd price-bot
```
(или распакуй `price-bot.zip` и зайди в папку через `cd`)

## Шаг 3. Установи библиотеки

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> **Обновляешься со старой версии?** Обязательно выполни
> `pip install -r requirements.txt` ещё раз — добавились новые библиотеки.

## Шаг 4. Настрой .env

Узнай свой Telegram ID у **@userinfobot**, затем:

```bash
cp .env.example .env
open -e .env
```

Впиши токен от @BotFather и свой ID, сохрани (⌘+S):
```
BOT_TOKEN=1234567890:AAEhBOweik...
ALLOWED_USER_ID=123456789
```

## Шаг 5. Запусти

```bash
python3 bot.py
```

Увидишь:
```
Регіон: Вінниця / Іллінці
Магазини: Сільпо, Грош, Фора, АТБ
Відповідаю тільки користувачу з ID 123456789
```

Окно Терминала не закрывай. Остановка — `Ctrl+C`.
В следующий раз можно просто дважды кликнуть `start.command`.

## Шаг 6. Проверь

1. `/start` → выбери магазины → «💾 Готово»
2. Первый запрос: бот скажет «🔄 Оновлюю каталог акцій…» (~30 сек, один раз)
3. Напиши `сир` → придут карточки с фото и ценами
4. Напиши `макарони` → мгновенно (индекс уже собран)
5. `/top` → топ скидок; `/deals` → листалка всех акций
6. `/list + молоко`, потом `/list` → проверка списка покупок
7. `/watch кава` → бот сообщит, когда появится скидка

## Если что-то не так

| Симптом | Решение |
|---|---|
| `ModuleNotFoundError` | `source .venv/bin/activate` затем `pip install -r requirements.txt` |
| `ImportError: InputRichMessage` | Старый aiogram: `pip install -r requirements.txt --upgrade` |
| Бот молчит | Проверь `ALLOWED_USER_ID` в `.env` (в логе будет «Ігнорую повідомлення від id=…») |
| `TelegramConflictError` | Бот запущен дважды — оставь одно окно |
| Пришёл текст вместо карточек | Обнови приложение Telegram (Rich Messages — с июля 2026) |
| Магазин «не відповів» | Сайт временно недоступен, остальные покажутся. `/refresh` позже |
| Мало акций у Гроша | У них небольшой онлайн-ассортимент — это нормально |

## Структура проекта

```
price-bot/
├── bot.py            # команды, кнопки, запуск, фоновое отслеживание
├── region.py         # ⭐ ID твоих магазинов (Вінниця/Іллінці) — меняй тут
├── deals_index.py    # локальный индекс акций (сердце скорости)
├── search_engine.py  # умный поиск: синонимы, опечатки, релевантность
├── rich.py           # красивый вывод: карточки с фото, таблицы
├── formatter.py      # текстовый вариант (запасной)
├── user_data.py      # список покупок, отслеживание, история
├── settings.py       # выбранные магазины
├── cache.py          # кэш поиска (3 часа)
├── config.py         # чтение .env
├── parsers/          # по одному файлу на магазин
│   ├── base.py       # общий каркас: паузы, таймауты, повторы
│   ├── silpo.py  grosh.py  fora.py  atb.py
└── .env              # твои секреты (в git не попадает)
```

## Как сменить магазин

Всё в одном файле — `region.py`:

- **АТБ**: `ATB_STORE_ID` (список магазинов города — в комментариях)
- **Фора**: `FORA_STORES` / `FORA_DEFAULT_FILIAL` (Вінниця 3745, Іллінці 4142)
- **Сільпо**: `SILPO_STORES` / `SILPO_DEFAULT_BRANCH`

## Вежливость к сайтам

Один запрос на страницу каталога, максимум 2 магазина одновременно,
паузы 1–3 сек, таймаут 20 сек, максимум 1 повтор, кэш 3 часа.
Никакого фонового кравлинга — только когда ты просишь (и раз в 3 часа
для отслеживаемых товаров).
