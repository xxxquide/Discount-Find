# 🛒 price-bot — личный бот скидок украинских супермаркетов

Telegram-бот, который по твоему сообщению ищет товары со скидками в сетях
**🟢 Сільпо, 🟣 Грош, 🟠 Фора, 🔵 АТБ** и присылает **красивое сообщение
с фотографиями товаров и настоящей таблицей цен**: магазин, название
(кликабельное), старая → новая цена, % скидки.

Бот работает прямо на твоём ноутбуке, отвечает **только тебе** и опрашивает
сайты **только в момент запроса** (никакого фонового сканирования).

## Что умеет

- 🏪 **Выбор магазинов.** При первом запуске бот предложит выбрать, где
  искать (кнопки-переключатели ✅/⬜). Изменить выбор — команда `/stores`.
  Выбор сохраняется между перезапусками.
- 🖼 **Красивый вывод.** Использует Rich Messages из Telegram Bot API 10.2
  (июль 2026): заголовок, коллаж фото самых выгодных товаров и таблица
  с рамками и «зеброй». Если rich-сообщение не доставится — бот сам
  пришлёт аккуратный текстовый вариант (без ответа не останешься).
- ⚡ **Кэш 3 часа.** Повторный запрос того же товара приходит мгновенно
  и не трогает сайты магазинов.
- 🤝 **Вежливость к сайтам.** Один поисковый запрос на магазин на товар,
  максимум 2 магазина одновременно, паузы 1–3 сек, таймаут 20 сек,
  не больше 1 повтора.
- 🛡 **Устойчивость.** Магазин упал/не ответил — бот честно напишет об этом
  и покажет результаты остальных.

## Как магазины опрашиваются (без браузера!)

| Магазин | Способ | Запросов на товар |
|---|---|---|
| 🟢 Сільпо | внутренний REST API сайта | 1 |
| 🟣 Грош | JSON API платформы Salesbox | 1 |
| 🟠 Фора | JSON API группы Fozzy | 1 |
| 🔵 АТБ | обычная HTML-страница поиска + разбор | 1 |

Playwright и другие «тяжёлые» инструменты не нужны.

# Установка на macOS (для новичка)

## Что понадобится

1. **Mac** с интернетом.
2. **Python 3.11 или новее.**
3. **Токен бота** от **@BotFather**.
4. **Твой Telegram ID** (получим на шаге 3).
5. Желательно **свежий Telegram** на телефоне/компьютере — красивые
   rich-сообщения появились в июле 2026, старый клиент покажет их упрощённо.

## Шаг 0. Открой Терминал

`⌘ + Пробел` → набери `Terminal` → Enter.

## Шаг 1. Проверь Python

```bash
python3 --version
```

Нужно `Python 3.11.x` или новее. Если старее — установи с
https://www.python.org/downloads/ и открой Терминал заново.

## Шаг 2. Получи проект и установи зависимости

**Вариант А (архив):** распакуй `price-bot.zip` двойным кликом.

**Вариант Б (git):**
```bash
git clone https://github.com/xxxquide/Discount-Find.git price-bot
```

Дальше одинаково:

```bash
cd ~/Downloads/price-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> Уже ставил(а) раньше? После обновления кода зайди в папку и выполни:
> `source .venv/bin/activate && pip install -r requirements.txt` —
> подтянутся новые библиотеки (aiogram 3.30+, beautifulsoup4).

## Шаг 3. Настрой .env (токен и твой ID)

1. Узнай свой Telegram ID у бота **@userinfobot** (напиши ему что угодно —
   ответит `Id: 123456789`).
2. Создай файл настроек и открой его:

```bash
cp .env.example .env
open -e .env
```

3. Впиши свои значения и сохрани (`⌘+S`):

```
BOT_TOKEN=1234567890:AAEhBOweik6ad9r_QXMENQjcrGbqCr4K-AB
ALLOWED_USER_ID=123456789
```

> ⚠️ Токен — «пароль» от бота. Файл `.env` остаётся только у тебя
> (в git он не попадает — исключён через .gitignore).

## Шаг 4. Запусти

```bash
python3 bot.py
```

Увидишь:

```
12:00:00 INFO    price-bot: Бот запущено. Реалізовані магазини: Сільпо, Грош, Фора, АТБ
12:00:00 INFO    price-bot: Відповідаю тільки користувачу з ID 123456789
```

Окно Терминала не закрывай. Остановка — `Ctrl+C`.

В следующие разы: `cd ~/Downloads/price-bot && source .venv/bin/activate && python3 bot.py`
или просто двойной клик по `start.command` (первый раз: правый клик → «Открыть»).

## Шаг 5. Проверь в Telegram

1. Нажми **Start** у своего бота.
2. Бот поздоровается и **предложит выбрать магазины** — потыкай кнопки,
   нажми «💾 Готово».
3. Напиши: `сир`
4. Придёт rich-сообщение: заголовок «🛒 Сир», коллаж фото и таблица скидок
   по выбранным магазинам (названия в таблице кликабельны).
5. Напиши `сир` ещё раз — ответ придёт мгновенно с пометкой «⚡ з кешу».
6. `/stores` — поменяй выбор магазинов в любой момент.

Можно несколько товаров сразу: `макарони, чіпси, сир` — по каждому
придёт отдельное сообщение.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `command not found: python3` | Установи Python с python.org (шаг 1) |
| `ModuleNotFoundError: aiogram` | Активируй окружение: `source .venv/bin/activate`, потом `python3 bot.py` |
| `ImportError: ... InputRichMessage` | Старый aiogram: `pip install -r requirements.txt --upgrade` |
| `Ошибка настройки: BOT_TOKEN…` | Открой `.env`, проверь токен |
| Бот молчит в Telegram | Проверь `ALLOWED_USER_ID`: в Терминале будет строка «Ігнорую повідомлення від стороннього користувача id=…» — впиши этот id и перезапусти |
| `TelegramConflictError` | Бот запущен дважды — оставь один |
| `SSL: CERTIFICATE_VERIFY_FAILED` | Finder → Программы → Python 3.x → «Install Certificates.command» |
| Пришёл текстовый ответ вместо таблицы | Это запасной вариант: обнови приложение Telegram; если не помогло — смотри лог бота (строка «Rich-повідомлення не пройшло…») |
| Магазин «не відповів» | Нормально: сайт мог прилечь или закрыться от дата-центров. Остальные покажутся. Попробуй позже |

## Как устроен проект

```
price-bot/
├── bot.py            # запуск, хэндлеры, выбор магазинов, rich-вывод + fallback
├── parsers/
│   ├── base.py       # каркас: Product, паузы, таймауты, повторы, релевантность
│   ├── silpo.py      # Сільпо — REST API сайта
│   ├── grosh.py      # Грош — JSON API Salesbox
│   ├── fora.py       # Фора — JSON API Fozzy
│   └── atb.py        # АТБ — HTML + BeautifulSoup
├── rich.py           # сборка rich-сообщения: заголовок, коллаж, таблица, футер
├── formatter.py      # классический текстовый вариант (запасной)
├── settings.py       # выбранные магазины (SQLite, переживает перезапуск)
├── cache.py          # кэш результатов на 3 часа (SQLite)
├── config.py         # чтение .env
├── requirements.txt  # библиотеки
├── start.command     # запуск двойным кликом
└── .env              # ТВОИ секреты (создаёшь сам из .env.example)
```

## Заметки о поиске

- Поиск **Форы** «буквальный» и её ассортимент в API небольшой: по слову
  «макарони» может быть пусто, а по «сир» — много. Это особенность сайта.
- **Грош** — региональная сеть (Винница и область), некоторых категорий
  (например, чипсов) в онлайн-ассортименте может не быть.
- Бот фильтрует результаты по релевантности, но понимает украинские
  варианты написания («чіпси» найдёт и «чипси»).
