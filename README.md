# 🛒 price-bot — личный бот скидок украинских супермаркетов

Telegram-бот, который по твоему сообщению ищет товары со скидками в сетях
**Сільпо, Грош, Фора, АТБ** и присылает: магазин, название, старую и новую
цену, % скидки и ссылку на товар.

Бот работает прямо на твоём ноутбуке, отвечает **только тебе** и опрашивает
сайты **только в момент запроса** (никакого фонового сканирования).

> Сейчас подключено: 🟢 **Сільпо** (этап 1).
> Дальше по плану добавляем: 🟣 Грош → 🟠 Фора → 🔵 АТБ.

---

## Что понадобится

1. **Mac** с интернетом.
2. **Python 3.11 или новее** (проверим на шаге 1).
3. **Токен бота** — ты его уже получил(а) у **@BotFather**.
4. **Твой Telegram ID** — получим на шаге 3, это одна минута.

---

## Шаг 0. Открой Терминал

Нажми `⌘ + Пробел` (Spotlight), напиши `Terminal`, нажми Enter.
Появится окно с приглашением ввода — все команды ниже вводим туда
и нажимаем Enter после каждой.

## Шаг 1. Проверь Python

```bash
python3 --version
```

Должно показать `Python 3.11.x` или новее (3.12, 3.13 — отлично).
Если версия старее или команда не найдена — скачай установщик с
https://www.python.org/downloads/ , установи и открой Терминал заново.

## Шаг 2. Перейди в папку проекта и установи зависимости

Если архив `price-bot.zip` лежит в «Загрузках», распакуй его двойным
кликом — появится папка `price-bot`. Затем в Терминале:

```bash
cd ~/Downloads/price-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Что это было:
- `cd …` — заходим в папку проекта;
- `python3 -m venv .venv` — создаём «виртуальное окружение» (изолированную
  песочницу для библиотек этого проекта, чтобы ничего не засорять в системе);
- `source .venv/bin/activate` — включаем её (в начале строки появится `(.venv)`);
- `pip install …` — ставим три библиотеки. Займёт с полминуты.

В конце должно быть что-то вроде `Successfully installed aiogram-3.x …`.

## Шаг 3. Настрой файл .env (токен и твой ID)

1. Узнай свой Telegram ID: открой в Telegram бота **@userinfobot**,
   нажми Start — он ответит строкой вида `Id: 123456789`. Это и есть твой ID.
2. Создай файл настроек из образца:

```bash
cp .env.example .env
open -e .env
```

3. Откроется текстовый редактор. Впиши свои значения:

```
BOT_TOKEN=1234567890:AAEhBOweik6ad9r_QXMENQjcrGbqCr4K-AB
ALLOWED_USER_ID=123456789
```

4. Сохрани (`⌘ + S`) и закрой редактор.

> ⚠️ Токен — это «пароль» от бота. Никому его не показывай.
> Файл `.env` остаётся только на твоём компьютере.

## Шаг 4. Запусти бота

```bash
python3 bot.py
```

Должны появиться строки вида:

```
12:00:00 INFO    price-bot: Бот запущено. Підключені магазини: Сільпо
12:00:00 INFO    price-bot: Відповідаю тільки користувачу з ID 123456789
12:00:00 INFO    price-bot: Зупинка: натисни Ctrl+C у цьому вікні Терміналу.
```

Окно Терминала **не закрывай** — пока оно открыто, бот работает.
Остановить бота: `Ctrl + C`.

### Запуск в следующие разы (коротко)

```bash
cd ~/Downloads/price-bot
source .venv/bin/activate
python3 bot.py
```

Или просто дважды кликни файл `start.command` в папке проекта
(при первом запуске macOS спросит разрешение: правый клик → «Открыть»).

## Шаг 5. Проверь в Telegram

1. Открой своего бота (ссылку/имя дал @BotFather), нажми **Start**.
2. Бот поздоровается и объяснит формат.
3. Напиши: `макарони`
4. Через несколько секунд придёт блок вида:

```
🛒 макарони

🟢 Сільпо — Макарони Garofalo «Спагеті» №5-9 Біо
   💸 119.00 → 94.99 грн (−20%)
   🔗 товар на сайті
```

5. Напиши `макарони` ещё раз — ответ придёт мгновенно и с пометкой
   «⚡ Результат з кешу»: повторные запросы 3 часа не трогают сайты.

Можно несколько товаров сразу: `макарони, чіпси, сир` —
придёт отдельное сообщение по каждому.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `command not found: python3` | Установи Python с python.org (шаг 1) |
| `ModuleNotFoundError: aiogram` | Ты не в venv: выполни `source .venv/bin/activate` и снова `python3 bot.py` |
| `Ошибка настройки: BOT_TOKEN…` | Открой `.env`, проверь токен (без пробелов, целиком) |
| Бот запустился, но молчит в Telegram | Проверь `ALLOWED_USER_ID` — бот игнорирует всех, кроме этого ID. В окне Терминала будет строка «Ігнорую повідомлення від стороннього користувача id=…» — впиши этот id в `.env` и перезапусти |
| `TelegramConflictError` | Бот запущен дважды. Закрой лишнее окно Терминала (или перезагрузись) и запусти один раз |
| `SSL: CERTIFICATE_VERIFY_FAILED` | Один раз запусти: Finder → Программы → Python 3.x → «Install Certificates.command» |
| Один из магазинов «не відповів» | Это нормально: сайт мог быть недоступен. Остальные магазины покажутся. Повтори запрос позже |

## Как устроен проект

```
price-bot/
├── bot.py            # запуск, обработка сообщений, белый список
├── parsers/
│   ├── base.py       # общий каркас: Product, паузы, таймауты, повторы
│   ├── silpo.py      # Сільпо — внутренний JSON API сайта ✅
│   ├── grosh.py      # Грош — этап 2 (рецепт уже проверен)
│   ├── fora.py       # Фора — этап 3 (рецепт уже проверен)
│   └── atb.py        # АТБ — этап 4 (рецепт уже проверен)
├── cache.py          # SQLite-кэш результатов, живёт 3 часа (файл cache.db)
├── formatter.py      # сборка красивого сообщения
├── config.py         # чтение .env
├── requirements.txt  # список библиотек
├── start.command     # запуск двойным кликом (для ленивых 😊)
└── .env              # ТВОИ секреты (создаёшь сам из .env.example)
```

## Принципы вежливости к сайтам (уже встроены)

- На один товар и один магазин — ровно **один** поисковый запрос
  (только первая страница результатов, никакого обхода каталога).
- Одновременно опрашиваются максимум **2** магазина.
- Между запросами к одному домену — пауза **1–3 секунды** (случайная).
- Таймаут 20 секунд, при ошибке — **один** повтор, не больше.
- Повторные запросы в течение **3 часов** берутся из кэша.
- Падение одного магазина не ломает остальные — бот всегда отвечает.
